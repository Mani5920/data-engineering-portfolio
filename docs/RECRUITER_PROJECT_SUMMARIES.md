# Recruiter-Friendly Project Summaries

## Enterprise Data Lakehouse Platform
Designed a medallion-style data platform that separates raw, validated and business-ready datasets, with orchestration, repeatable transformations and analytics-ready outputs.

## Customer 360 Cloud Data Warehouse
Built a dimensional warehouse that consolidates customer and transaction data into a governed analytical view using repeatable ETL, relational modelling and automated validation.

## Real-Time Customer Analytics Platform
Developed an event-driven pipeline that ingests customer activity through Kafka-compatible messaging, processes streams in Python and persists events for near-real-time analytics.

## Enterprise Banking Data Governance & Quality Platform
Created a governance and data-quality framework demonstrating metadata, lineage, reconciliation, exception handling and audit-oriented reporting for regulated data environments.
