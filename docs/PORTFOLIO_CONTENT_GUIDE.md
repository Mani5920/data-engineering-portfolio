# Portfolio Content Guide

## Personal positioning

**Primary title:** Data Engineer

**Supporting positioning:** SQL · Python · Azure Data Services · ETL/ELT · Data Warehousing · Data Quality · Analytics Engineering

Use PKI and systems experience as a differentiator for secure, regulated and operationally reliable data platforms—not as the main portfolio theme.

## Recruiter story

1. Mani understands enterprise operations and regulated environments.
2. He can build ingestion and transformation workflows.
3. He can model, validate and reconcile data.
4. He can communicate results through BI and documentation.
5. His GitHub provides tangible engineering evidence.

## Project documentation standard

Every repository should include:

- Business problem
- Architecture diagram
- Source-to-target flow
- Technology choices
- Setup instructions
- Data model
- Quality checks
- Tests
- Screenshots
- Limitations
- Future improvements

## Accuracy rule

Only publish technologies, employers, volumes, metrics and outcomes that can be supported honestly in an interview. Label simulated data and portfolio-scale benchmarks clearly.
